# galagain.com

Source code for my personal website.

The site is currently a lightweight static frontend built with plain HTML, CSS,
and JavaScript. It includes my profile, CV link, publications, education,
teaching, experience, and a contact form.

## Structure

- `index.html` - main page markup
- `styles.css` - visual layout and responsive styles
- `script.js` - page interactions and animations
- `data/` - avatar images
- `cv.pdf` - public CV served from the website

## Local Preview

Run a small local server from the repository root:

```bash
python3 -m http.server 8765
```

Then open:

```text
http://localhost:8765
```
